Gesture Cam

Webcam effects for Discord, set off by hand gestures: thumbs up for fireworks, peace sign for confetti, and more. The effects play behind you, so they never cover your face. Linux only, made for Arch (pacman).

Download Gesture Cam

Installing

  1. Install the window's libraries: 
    sudo pacman -S --needed python-gobject gtk4 libadwaita
  2. Unpack the download in your home folder and go into it: 
    tar xzf ~/Downloads/gesture-cam.tar.gz -C ~
cd ~/gesture-cam
  3. Create the virtual camera (once). It asks for your password: 
    sudo ./setup-loopback.sh
  4. Set up Python and add Gesture Cam to your app launcher: 
    python3 -m venv --system-site-packages .venv
.venv/bin/pip install -r requirements.txt
sed "s#^Exec=.*#Exec=$PWD/gesture-cam#" gesture-cam.desktop > ~/.local/share/applications/gesture-cam.desktop

Using it

  1. Turn your camera off in Discord or Vesktop first. Gesture Cam needs the real webcam for itself.
  2. Open Gesture Cam from your app launcher, and keep its window open while you use it.
  3. In Discord, go to Settings → Voice & Video → Camera and pick Gesture Cam. Restart Discord the first time, so it sees the new camera.

The README in the download explains the settings and the gestures.
