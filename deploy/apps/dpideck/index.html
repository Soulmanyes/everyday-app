DPIdeck

Settings for ATK / VXE mice, such as the VXE MAD R, on Windows and Linux. No ATK HUB website or Chromium-based browser needed. It works over the 2.4 GHz dongle and over the USB cable.

It changes DPI stages, polling rate (up to 8000 Hz, depending on the connection), sensor mode, lift-off distance, motion sync, angle snapping, ripple control, long range mode, the DPI and receiver lights, click debounce, the sleep timer and the button mapping. Settings are saved in the mouse itself.

Windows

Download for Windows

Unzip it and run DPIdeck.exe. Nothing needs installing. Windows may say "Windows protected your PC" because the app isn't signed: click More info, then Run anyway.

Linux

Run this in a terminal. It asks for your password once, to install what DPIdeck needs and to let your user talk to the mouse:

curl -fsSL https://raw.githubusercontent.com/Soulmanyes/dpideck/main/install.sh | sh

Then open DPIdeck from your app menu. If the mouse isn't found, unplug it (or its dongle) and plug it back in. Run the same command again to update. Works on Arch, Debian/Ubuntu, Fedora and openSUSE.

Source code, the full list of supported mice and how to uninstall: github.com/Soulmanyes/dpideck. DPIdeck's own code is public domain (CC0 1.0); the parts it builds on keep their own licenses, listed in the repository. It isn't made by ATK.
