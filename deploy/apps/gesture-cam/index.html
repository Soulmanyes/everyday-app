Gesture Cam

Webcam effects for video calls and camera apps, set off by hand gestures: thumbs up for fireworks, peace sign for confetti, and more. The effects play behind you, so they never cover your face. Linux: Arch (and Arch-based distros), Debian 13+, Ubuntu 24.04+ and Fedora 40+.

It shows up as an extra camera called Gesture Cam. Tested in Discord, Vesktop and GNOME Snapshot. Other apps that let you pick a camera (browsers, Zoom, OBS) should work too, but haven't been tried yet.

Download Gesture Cam

Installing

Run this in a terminal. It asks for your password the first time, to install what Gesture Cam needs and create the virtual camera:

curl -fsSL https://raw.githubusercontent.com/Soulmanyes/gesture-cam/main/install.sh | sh

It puts the app in ~/.local/share/gesture-cam, downloads MediaPipe's two models from Google and adds Gesture Cam to your app launcher. On Fedora it also turns on the RPM Fusion repository, where the camera driver comes from. Run the same command again to update.

Or use the download: unpack it where you want to keep it, then run the installer from that folder:

tar xzf ~/Downloads/gesture-cam.tar.gz -C ~
~/gesture-cam/install.sh

Secure Boot on? Then the camera driver is blocked at first, and the installer prints a sudo mokutil --import … command. Run it and pick a one-time password. Reboot: on the blue screen, choose Enroll MOK → Continue → Yes, type the password and reboot again. Then run the installer once more.

Using it

  1. Turn your camera off in Discord, Vesktop and other camera apps first. Gesture Cam needs the real webcam for itself.
  2. Open Gesture Cam from your app launcher, and keep its window open while you use it.
  3. In your app, pick Gesture Cam as the camera. In Discord, that's Settings → Voice & Video → Camera. It's only listed while Gesture Cam is on, so open or restart the app after turning Gesture Cam on.

The README in the download explains the settings and the gestures. Gesture Cam's own code is public domain (CC0 1.0). The libraries and models it installs keep their own licenses, listed in the README.
